rFabric Linux packages

apt and dnf repository for the rFabric CLI (rfabric), robot agent (rfabric-agent) and remote (rfabric-remote). The installers add it for you:

curl -fsSL https://get.rfabric.io/cli.sh | sh      # CLI
curl -fsSL https://get.rfabric.io/agent.sh | sh    # robot agent

Upgrades arrive with apt-get upgrade / dnf upgrade. Signing key: rfabric.asc.
